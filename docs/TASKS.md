| # | 규칙 |
|---|---|
| 1 | **티켓 1개 = 1세션**. 범위 밖 파일은 건드리지 않는다. |

| 3 | 티켓 완료 시 ① 이 문서의 상태 ② `engine/README.md` 검증 기록 ③ 커밋 — 3개를 같이 한다. |

| 7 | 라이선스 미확인 모델은 설치 금지(**Q9**). 확인 전 티켓은 🚫로 둔다. |
| 8 | 티켓·실험 종료 시 `docs/WORKLOG.md`에 **run_id·조건·단계별 소요·결과 1행**을 추가한다. 측정 없는 "완료"는 인정하지 않는다. |

```powershell
.\mokhwa.cmd env check                  # 종료 코드 0

.\mokhwa.cmd make --topic "..." --seconds 10 --width 832 --height 480 --steps 6   # 스모크
```
