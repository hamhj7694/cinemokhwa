# P2 하이브리드 제품 요구사항 — 계획 정본 v0.1

> 2026-11-26 / 상태: **구현 설계 기준선(제안)**. 장기 제품 요구는 `PRD.md`에 보존하되 P2 파일럿은 이 문서가 우선한다. 목표와 현재 구현을 혼동하지 않는다.

## 제품 목표
소수의 실사 기준 이미지와 장면 설명을 입력하면 **Blender가 시간·공간 배치를, 이미지 모델이 외형·질감을, 영상 모델이 움직임의 실사화를** 담당하는 로컬 하이브리드 제작 파이프라인. 12GB VRAM PC에서 재실행·수정·비교 가능해야 한다.

### 사용 사례와 사용자 작업
- **파일럿 (첫 출시 목표 H2/H3):** 기획자가 텍스트 한 줄 + 적법한 단일 인물 기준 사진 1장을 넣어 3~5초 단일 샷 생성; Blender 프리비즈와 생성 영상의 인물 위치·방향·카메라 변화를 비교; 실패하면 부분 재시도.
- **확장 (H4/H5):** 인물·소품·배경 레퍼런스를 구별된 ID로 보관하고, 동일 인물 여러 샷 및 여러 객체의 시간별 이동을 추적.
- **장기 (H6 이후):** 15초 이상 편집, 대화형 UI, 녹음/전사/자막/TTS/립싱크, 장르·애니메이션 모드. 초기에 구축 대상으로 확정하지 않는다.

## 비기능 요구사항
- NFR-01 **성능**: RTX 3060 12GB, Windows 10, RAM 32GB에서 피크 VRAM·생성 벽시계·GPU OOM·해상도 기록. 성능 목표(15초 70분)는 **미달 리스크**이며 기존 실측을 성공 증거로 오인하지 않는다.
- NFR-02 **안전/저장**: 기본은 로컬 처리. 사용자 참조 이미지/음성/결과 영상은 git 업로드 금지. 출처, 동의·사용 권한을 최소 메타로 관리.
- NFR-03 **재현성**: 모델 파일 해시/버전, seed, 설정, 프롬프트, 샷/개체 트랙, 단계별 시작/종료/상태를 기록.
- NFR-04 **정확성**: 얼굴/위치/장면 경계 자동 기준은 보조. 사람이 실제 24fps 결과 영상을 보고 `accept/reject` 판단.
- NFR-05 **확장성**: 단계 간 버전 계약, 단독 모듈 테스트 가능, 코드 모듈별 파일 소유권, 성능 병렬 실행 금지.
- NFR-06 **라이선스**: 모델 다운로드·이용·배포 전 공식 라이선스 최신 원문 재확인. 11/21 조사표만으로 영리 이용 승인 불가.

## 필수 입력과 산출물(파일럿)
- **입력:** 텍스트 주제, 원하는 동작/길이, 허용된 레퍼런스 1장, 스타일(초기 실사 1종), seed 옵션.
- **중간:** `script.json` → `scene_spec.json` → `previs/` 시간별 RGB/geometry/tracks → `assets/` 참조/실사 앵커 → `clips/` 영상 → `checks/` 자동/육안 결과.
- **출력:** 비디오 파일 + `manifest.json`(재현정보) + `evaluation.json` + 확인 가능한 로그.
- 스키마의 필드와 실제 저장 경로는 `P2_CONTRACTS.md`를 따른다. 추후 구현 전 계약 테스트로 확정한다.

## 비목표(초기)
처음부터 15초 모든 샷, 다인물, 실사 3D 직접 메시 텍스처 매핑, 범용 3D 모델 생성, 음성/립싱크, 웹 UI, 원클릭 상용 품질을 **동시에** 구현하지 않는다. Blender 프리비즈와 생성 결과의 위치 오차는 생성 모델 특성상 0을 보장하지 않는다.

## 릴리스 규칙
- **H1:** 스키마/에이전트/실측 기준 합의. 생성 품질 성공 아님.
- **H2:** Blender 시간축 프리비즈 및 인물 실사 앵커의 입력/출력이 단위 테스트로 확인됨.
- **H3:** 실제 LTX 3~5초 단일 샷 P2 E2E + 기준 영상 대비 평가 + 육안 승인(또는 실패 근거와 결정) 기록.
- **H4:** 다객체 ID/가이드 추적 검증. **H5:** 두 샷 이상 일관성/조립 검증. **H6:** API/UI/음성은 H3/H5 성립 후 선택.
- 각 게이트의 상세 수치는 `P2_TEST_PLAN.md`의 **가설/미확정 기준**과 구분한다.
