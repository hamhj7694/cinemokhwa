## 1. 디자인 목표

| # | 목표 | 판정 |
|---|---|---|
| DG1 | 첫 화면이 **대화**다. 툴이 아니라 감독과 대화하는 느낌 | S1 진입 시 입력창이 포커스 |

| DG4 | 결과물이 **영화처럼** 보인다 (크리에이티브 툴 톤, 다크 기본) | 다크 모드 시각 검수 |

### 톤 키워드

`차분함` · `직조(織造)` · `필름 그레인` · `따뜻한 먹색` · `정밀한 도구`

> 목화(棉花)에서: **면(綿)의 부드러움 + 직조의 규칙성**. 둥근 모서리(면) + 정확한 그리드(직조).

- 최소 터치/클릭 영역 32×32 (데스크톱), 아이콘 24

- **focus-visible은 반드시 2px `accent` 링** (키보드 접근성)
- 로딩은 스피너보다 **스켈레톤 + 진행률** 우선

## 11. Figma 제작 순서 (실행 확정)

> **제약 확정**: Starter 플랜 = **페이지 3개 · 컬렉션당 모드 1개**. 아래 3페이지로 압축한다.
> 파일: `씨네목화 — Product Design` (fileKey `pT68j17duxcGL2tdMfdFQd`)

| 페이지 | 내용 |
|---|---|
| `01 Design System` | F0 브랜드 / F1 컬러 / F2 타이포 / F3 스페이싱·라디우스 / F4 컴포넌트 1 / F5 컴포넌트 2 |
| `02 Screens` | S0 · S1 · S2 · S3 · S4 · S5 (각 1440×900, 120px 간격 그리드) |
| `03 Handoff` | 토큰 표 · 컴포넌트 인벤토리 · 구현 매핑 · 열린 이슈 |

1. Foundations는 보드가 아니라 **Variables + Text Styles**가 진실. 보드는 시각 확인용.
2. 컴포넌트는 F4/F5에 모아두고, 화면은 같은 토큰으로 조립 (인스턴스화는 상태 변형 추가 시).
3. 화면은 S1 → S2 → S3 → S0 → S4 → S5 순서.
4. 라이트 테마는 `Color Light` 컬렉션으로 분리되어 있고, 화면은 `Color(Dark)`을 바인딩한다.

**완료 정의**: ① S1~S3 존재 ② 컴포넌트 라이브러리 존재 ③ 토큰이 Variables로 존재 ④ 넘침 0 ⑤ Handoff 1장

1. eyebrow 라벨 금지
2. tracked capitals / small caps 금지
3. 헤드라인 안에서 단어별 색 바꾸기 금지
